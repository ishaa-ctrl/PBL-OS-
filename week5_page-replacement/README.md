# Page Replacement Algorithms

## Project Overview
A C-based simulation and comparative analysis of three operating system page replacement algorithms.

## Algorithms
- FIFO (First In, First Out)
- LRU (Least Recently Used)
- Optimal Page Replacement

## Features
- User input for page references and frame count
- Step-by-step page frame simulation
- Page hit and page fault tracking
- Hit ratio and fault ratio calculation
- Comparison of all three algorithms

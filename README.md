# Operating Systems PBL

**Course:** Operating Systems (OSCO)  
**Language:** C  
**Tools:** GCC, VS Code, Git, GitHub, Linux/Ubuntu

## 📌 About the Project

This repository contains the practical work completed as part of our Operating Systems Project-Based Learning (PBL). Over three weeks, we explore process communication, multi-process architecture, and CPU scheduling through C programming.

## 📚 Weekly Overview

### Week 1: Inter-Process Communication (IPC)
- Understanding communication between independent processes.
- Exploring named pipes (FIFOs).
- Learning process coordination and data exchange.

### Week 2: Three-Process OS Simulator
- Developing UI, Core, and Logger processes.
- Using POSIX named pipes for inter-process communication.
- Implementing command handling and logging.

### Week 3: Process Scheduling Simulator
- Implementing six CPU scheduling algorithms: FCFS, Non-Preemptive SJF, Preemptive SJF (SRTF), Non-Preemptive Priority, Preemptive Priority, and Round Robin.
- Generating Gantt charts.
- Calculating CT, TAT, WT, RT, average waiting time, average turnaround time, and CPU utilization.

## 🎯 Project Objectives

- Understand fundamental operating system concepts.
- Implement IPC using named pipes.
- Design and develop multi-process systems.
- Explore CPU scheduling algorithms and compare their performance.
- Practise C programming, debugging, testing, and collaboration.

## 🛠️ Technologies Used

- **C** – Implementation
- **GCC** – Compilation
- **Linux/Ubuntu** – Execution environment for POSIX IPC
- **VS Code** – Development
- **Git and GitHub** – Version control and collaboration

## 📈 Learning Outcomes

Through this PBL, we gain practical experience with inter-process communication, multi-process system design, CPU scheduling, performance evaluation, and collaborative software development.

## Conclusion

This project connects operating system theory with practical implementation. Across three weeks, we progress from IPC fundamentals to a multi-process simulator and CPU scheduling, strengthening our understanding of how operating systems coordinate processes and manage CPU resources.

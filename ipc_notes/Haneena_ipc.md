1. What is IPC?

Interprocess Communication (IPC) is a mechanism that allows two or more processes to communicate and exchange data with each other.

Each process normally has its own memory space. IPC provides methods that allow processes to share information and coordinate their activities.

Common IPC techniques

Pipes

Shared Memory

Message Passing

Message Queues

Sockets

Signals


2. Why is IPC Needed?

IPC is needed because processes often need to work together and exchange information.

Main purposes of IPC:

Data sharing: Allows processes to exchange data.

Process coordination: Helps processes work together.

Synchronization: Controls the order in which processes perform tasks.

Resource sharing: Allows processes to use shared resources efficiently.

Communication: Allows one process to send information or notifications to another.


3. Basic Working of IPC

The basic idea of IPC is:

Process A
    ↓
 Sends data / signal
    ↓
  IPC Mechanism
    ↓
Process B
    ↓
Receives data / signal

For example, Process A can send information to Process B using a pipe or message queue.

Different IPC techniques provide different ways for processes to communicate.

4. What are Signals?

A signal is a notification sent to a process to inform it that a particular event has occurred.

Signals are mainly used to notify or control processes, rather than to transfer large amounts of data.

For example, a process can receive a signal telling it to:

Stop

Continue

Terminate

Handle a particular event


Basic flow

Process A
    ↓
 Sends Signal
    ↓
Process B
    ↓
Handles Signal

5. Common Signals

Some commonly known signals in Unix/Linux systems are:

Signal	Meaning

SIGINT	Interrupts a process, commonly generated by Ctrl+C
SIGTERM	Requests a process to terminate
SIGKILL	Forces a process to terminate
SIGSTOP	Stops/suspends a process
SIGCONT	Continues a stopped process

6. Simple Real-World Example

Suppose a program is running in a terminal.

When the user presses:

Ctrl + C

the operating system sends SIGINT to the running process.

User
  ↓
Ctrl + C
  ↓
Operating System
  ↓
SIGINT
  ↓
Running Process

The process can then handle the signal and stop its execution.

7. Simple Python Example

Python provides the signal module for handling signals.

import signal

def handle_signal(signum, frame):
    print("Signal received!")

signal.signal(signal.SIGINT, handle_signal)

print("Running... Press Ctrl+C")

while True:
    pass

Here:

SIGINT is generated when Ctrl+C is pressed.

signal.signal() tells Python which function should handle the signal.

handle_signal() runs when the signal is received.

8. Conclusion

IPC allows processes to communicate, exchange information, and coordinate their activities. Signals are a simple IPC mechanism mainly used to notify or control processes when an event occurs.

In short:

> IPC = Communication between processes
Signal = Notification sent to a process
